# Node2Vec-Algorithm-and-Quantum-Walk-Variant
This Project was done under the supervision of Professor MS Santhanam of IISER Pune, where I studied the Node2Vec Algorithm used to Embed Nodes of a Network as Vectors in a vector space. The algorithm also uses an interesting biased random walk, which by tuning walk parameters can mimic properties of a breadth first search or a depth first search. We further studied its Quantum walk variant Q_walk_vec.
